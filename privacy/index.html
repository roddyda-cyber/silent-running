Silent Running Poster: Privacy Policy

Last updated October 31, 2026

Silent Running Poster is a private tool used by one person, the owner of the "My Silent Running" accounts on Facebook, Instagram, TikTok and YouTube (@mysilentrunning, @MySilentRunning). It uploads and schedules that person's own travel videos to their own accounts. It is not offered to the public, and nobody else can sign in to it.

What it collects

Nothing from visitors, followers or other Facebook users. The tool only uses an access key for the owner's own Page, which is stored on the owner's personal computer. It does not read messages, comments, followers or anyone's personal information.

What it shares

Nothing. No data is sold, shared or sent anywhere except to Facebook, to publish the owner's own videos.

YouTube

Silent Running Poster uses YouTube API Services to upload the owner's own videos to the owner's own YouTube channel (@MySilentRunning) and to schedule when they become public. By using it, the owner agrees to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

The tool asks Google only for permission to upload videos and to see the owner's own channel name. It does not read, store or share any YouTube data about viewers or other channels. It keeps only the ID and upload status of the owner's own uploads, on the owner's own computer, so the same video is never uploaded twice. The sign-in token is stored in Windows Credential Manager on that computer and never leaves it except to talk to Google.

Access can be removed at any time at Google security settings (third-party access). When access is removed, or on request, the stored upload records and token are deleted within 7 days.

Data deletion

The tool keeps no data about any user. The owner can stop it at any time by removing the app in Facebook Settings, under Business Integrations, or in Google security settings for YouTube, which ends its access. If you believe the tool holds data about you, message the Page at facebook.com/mysilentrunning and it will be confirmed or deleted within 30 days.
